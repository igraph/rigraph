# `architecture/`

What the shipped code is, and who wrote it.
The area divides by authorship rather than by language:
some of what ships is written here, some is generated from a specification, and some is vendored from the igraph C library.

**Little of what ships was typed where it is read.**
`R/aaa-*.R` and `src/rinterface.c` are generated by Stimulus, `src/cpp11.cpp` and `R/cpp11.R` by cpp11,
and `src/vendor/cigraph/` is copied from upstream,
so the first thing a leaf says about a file is which of those it is,
and a correction goes to the producer, never to the file in front of you.

* [`r-layer/`](r-layer/): the R this package writes, its conventions, its documentation, and what a new function needs
* [`glue/`](glue/): the hand-written C and C++ in `src/` between R and the C library
* [`stimulus/`](stimulus/): the generator that writes the R/C interface from `interfaces/*.yaml`
* [`engine/`](engine/): the vendored igraph C library under `src/vendor/`
