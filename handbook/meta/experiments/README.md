# Experiments

Where a measurement a leaf leans on gets recorded, what earns a record, and the shape one takes.
The convention has one home,
[`cynkra/handbook-tools`](https://github.com/cynkra/handbook-tools/blob/main/handbook/meta/experiments/README.md),
and this page points there rather than carrying a copy, so that every handbook built on it reads one text.
What this repository decides for itself, where the shared rules leave a choice open, is [`meta/local/`](/handbook/meta/local/README.md)'s,
and `.handbook-source` at the root names the state of the source this handbook was last checked against.
