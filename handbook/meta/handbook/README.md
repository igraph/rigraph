# The handbook's rules

The handbook is a strict topic hierarchy with full cover:
every aspect of this repository that may need documentation has exactly one place in this tree.
The rules that say what a page must do have one home,
[`cynkra/handbook-tools`](https://github.com/cynkra/handbook-tools/blob/main/handbook/meta/handbook/README.md),
and this page points there rather than carrying a copy, so that every handbook built on them reads one text.
What this repository decides for itself, where the shared rules leave a choice open, is [`meta/local/`](/handbook/meta/local/README.md)'s,
and `.handbook-source` at the root names the state of the source this handbook was last checked against.
