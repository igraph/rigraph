# Working on rigraph

This repository is the R package igraph, for network analysis and graph
theory: the R layer in `R/`, the C glue in `src/` that bridges it to the
igraph C library, an R/C interface generated by Stimulus, and a vendored
copy of the C library in `src/vendor/cigraph/`.

Everything this project documents lives in
[`handbook/`](https://r.igraph.org/handbook/README.md), the single
source of truth. This page only routes there.

## The first five minutes

- get a working environment:
  [`contributors/setup/`](https://r.igraph.org/handbook/contributors/setup/README.md)
- make a change, from branch to merged, with the commit and pull request
  style:
  [`contributors/workflow/`](https://r.igraph.org/handbook/contributors/workflow/README.md)
- run the suite, or one test file:
  [`testing/suite/`](https://r.igraph.org/handbook/testing/suite/README.md)
- write R the way this package does:
  [`architecture/r-layer/conventions/`](https://r.igraph.org/handbook/architecture/r-layer/conventions/README.md),
  [`documentation/`](https://r.igraph.org/handbook/architecture/r-layer/documentation/README.md)
  and
  [`new-functions/`](https://r.igraph.org/handbook/architecture/r-layer/new-functions/README.md)
- change the generated R/C interface, which is never edited by hand:
  [`architecture/stimulus/`](https://r.igraph.org/handbook/architecture/stimulus/README.md)
- operate the vendoring loop:
  [`operations/vendoring/series-loop/`](https://r.igraph.org/handbook/operations/vendoring/series-loop/README.md)
  and `.claude/skills/series-*`
- adapt the R side to a change in the C library:
  [`operations/vendoring/adaptation/`](https://r.igraph.org/handbook/operations/vendoring/adaptation/README.md)
- write a sentence the way this repository does, before you write one:
  [`meta/authoring/`](https://r.igraph.org/handbook/meta/authoring/README.md)
  and
  [`meta/style/`](https://r.igraph.org/handbook/meta/style/README.md)
- know what this repository decides for itself:
  [`meta/local/`](https://r.igraph.org/handbook/meta/local/README.md)

## Everything else

Anything not on this page is in the tree, and walking down from
[`handbook/`](https://r.igraph.org/handbook/README.md) is how you find
it: internal nodes navigate, leaves explain, and every fact has exactly
one leaf that owns it, including the limits, the declined requests, and
the reasons ([the
rules](https://r.igraph.org/handbook/meta/handbook/README.md)).

## Behaviour

- Every document outside `handbook/` either derives from it or
  backreferences the node it serves. In Claude Code the prose rules load
  on their own when you touch a file carrying prose; run `/docs:check`
  after touching documentation.
