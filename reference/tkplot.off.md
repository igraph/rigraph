# Interactive plotting of graphs

**\[deprecated\]**

`tkplot.off()` was renamed to
[`tk_off()`](https://r.igraph.org/reference/tkplot.md) to create a more
consistent API. As
[`tkplot()`](https://r.igraph.org/reference/tkplot.md) is defunct,
neither function has a plot to act on.

## Usage

``` r
tkplot.off()
```
