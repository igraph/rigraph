# The igraph console

**\[deprecated\]**

`igraph.console()` was renamed to
[`console()`](https://r.igraph.org/reference/console.md) to create a
more consistent API. As
[`console()`](https://r.igraph.org/reference/console.md) is defunct,
`igraph.console()` throws an error after its deprecation warning.

## Usage

``` r
igraph.console()
```
